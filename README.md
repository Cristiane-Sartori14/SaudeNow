# SaúdeNow

Aplicativo mobile desenvolvido em React Native e Expo para auxiliar idosos no gerenciamento da rotina de saúde.

## Tecnologias

- React Native
- Expo
- TypeScript
- Expo Router
- SQLite
- Context API
- Git

## Funcionalidades

- Cadastro de medicamentos
- Agenda de consultas
- Exercícios de mobilidade
- Banco de dados SQLite
- Interface acessível

## Objetivo

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas da UNISINOS.
